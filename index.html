¿Qué es la Web?

La World Wide Web, conocida como la Web, es un sistema de páginas y recursos enlazados que podemos consultar mediante un navegador. Utiliza Internet para compartir información, pero Web e Internet no significan exactamente lo mismo.

Este sitio presenta una explicación sencilla de sus orígenes, las tecnologías que la hacen posible y algunos momentos importantes de su desarrollo.

Una diferencia importante

Internet y la Web

Internet es una red mundial de redes y dispositivos. La Web es uno de los servicios que funciona sobre esa infraestructura, junto con otros servicios como el correo electrónico.
